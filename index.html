知识卡 · 八年级物理

光线怎么走，
清晰范围就怎么变。

不用公式。只要看懂凸透镜的会聚、光圈和光斑，就能解释这个现象。

知识卡 01 凸透镜

镜头像一块凸透镜

凸透镜对光有会聚作用。景物反射的光进入镜头后，会向中间收拢，寻找自己的会聚点。

记住光线穿过镜头，会向中间会聚。

知识卡 02 光圈

光圈像一扇可大可小的窗

f 值是相机上表示光圈大小的刻度。f 值越小，光圈开得越大，通过镜头的光束越粗；f 值越大，光圈收得越小，光束越细。

记住f 值小 → 光圈大 → 光束粗。

知识卡 03 对焦

对焦：让光正好聚在传感器上

传感器是相机里记录光线的部件。物体处于对焦位置时，传感器上得到一个清楚的像点。传感器若在会聚点前面或后面，截到的就是一个有大小、看起来发虚的光斑。

记住光斑越大，看起来就越模糊。

知识卡 04 清晰范围

光束越粗，越怕“对不准”

同样只偏离一点，粗光束在传感器上形成的光斑更大，更容易模糊；细光束的光斑更小，前后更宽的一段距离都还算清楚。

记住大光圈让光斑长得快，清晰范围就更窄。

把四张卡连起来 结论

不是对焦面变小，
是清晰范围变窄。

光圈不会移动对焦位置。它改变的是通过镜头的光束粗细，因此改变了“稍微偏离对焦后，光斑变大的速度”。

平时说“光圈越大，焦平面越小”，更准确的说法是：大光圈让景深（清晰范围）变窄。

光圈开大 光束更粗
→
偏离对焦 光斑更大
→
结果 清晰范围更窄

约定：数值基于 50 mm 镜头、全画幅传感器和几何光学近似；光斑不超过 0.03 mm 视为清晰。

进阶附录 · 几何光学

把“模糊”写成公式。

选读。用薄透镜近似，从物距、像距推出弥散圆，再把 c = c₀ 解成景深的两个边界。本页取 50 mm 焦距、全画幅传感器，c₀ = 0.03 mm。

01 · 薄透镜成像 THIN LENS

先确定像点

1/f = 1/u + 1/v

f 是焦距，u 是物距，v 是像距。相机对焦在 s 时，传感器位于对应的对焦像距 vf 上。

vf = fs / (s − f)

02 · 离焦弥散圆 CIRCLE OF CONFUSION

传感器截到多宽？

c = D · |v − vf| / v

D 是物理孔径，D = f/N；N 是 f 值。物距和对焦距离固定时， 弥散圆直径 c 与 D 成正比。

D = f / N ⇒ c ∝ 1/N

关键关系：大光圈 = 小 N = 大 D = 大 c。这就是“大光圈景深浅”的几何原因。

03 · 超焦距与景深 HYPERFOCAL / DOF

令 c = c₀，解出两个边界

H = f² / (Nc0) + f

un = s(H − f) / (H + s − 2f)

uf = s(H − f) / (H − s)

DoF = uf − un

H 是超焦距。若 s < H，远界有限；若 s ≥ H，远界为无穷远。公式内所有长度统一用 mm。

术语表 GLOSSARY

符号与概念

这些词在摄影、光学和本页计算里的含义。

对焦平面（物方）
场景中距离 s 的物平面；它的共轭像面就是传感器所在的像平面。光圈大小不会移动它。
焦平面（像方）
对焦光线会聚的像平面；合焦时与传感器面重合。口语里的“焦平面”有时其实指传感器面。
物理孔径 D
有效通光直径，D = f / N。
f 值 N
摄影里的光圈刻度，N = f / D；数值越小，光圈越大。
像距 v / vf
物距 u、对焦距离 s 各自对应的像面位置。
弥散圆 c（CoC）
离焦物点在传感器上形成的圆形光斑直径；c 越大越模糊。
允许弥散圆 c₀
“看起来仍清晰”的光斑上限。本页按全画幅取 0.03 mm。
景深 DoF
满足 c ≤ c0 的物距范围，即 un 到 uf 之间。
超焦距 H
使景深远界为无穷远的最小对焦距离。
全画幅 FF
36 × 24 mm 传感器。不同画幅采用不同的 c₀，景深刻度不能直接套用。
薄透镜近似
把镜头视作理想薄透镜；忽略像差、衍射和镜头主平面间距。
衍射极限
光圈很小时，波动光学使光斑无法继续变小；圆孔衍射斑近似直径 2.44 λN。

常见误称：“焦平面变小”把“面”和“深度范围”混在了一起。光圈不会移动对焦平面，只会让可接受的物距范围（景深）变窄。

推导链 DERIVATION

从相似三角形到景深边界

  1. 01

    定位像点

    由薄透镜公式 v = fu/(u − f)，把物距换成像距；对焦面 s 对应 vf。

  2. 02

    量出光斑

    孔径两端的光线在像点会聚。传感器若在像点前 / 后，截出的光斑满足 c/D = |v − vf|/v。

  3. 03

    解出景深

    令 c = c0，解出两个物距 un、uf，两者之间就是景深。

模型边界： 上述数值只考虑几何光学，采用 50 mm 薄透镜、全画幅和 c₀ = 0.03 mm。真实镜头的像差、衍射、对焦距离标定和焦距呼吸都会造成偏差。圆孔衍射斑的近似直径为 2.44 λN；取 λ ≈ 550 nm、N = 22 时约为 30 µm，已经与允许弥散圆同量级，所以极小光圈未必更清楚。画布中的距离和光线位移经过视觉放大，不按真实比例绘制。
